# online-qr-code-scanner-tool# 🚀 Free Online QR Code & Barcode Scanner Tool

A fast, browser-based, client-side QR Code Scanner and Barcode Reader supporting webcam stream, mobile camera, and image uploads with 100% privacy protection.

## ✨ Features
- 100% Client-side decoding (No server uploads)
- Image file support (PNG, JPG, WEBP)
- Barcode decoding (EAN-13, UPC, Code 128, Data Matrix)
- Responsive mobile & desktop browser support
