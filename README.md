## ✨ Features
- 100% Client-side decoding (No server uploads)
- Image file support (PNG, JPG, WEBP)
- Barcode decoding (EAN-13, UPC, Code 128, Data Matrix)
- Responsive mobile & desktop browser support
- ## 🛠️ Complete Suite of In-Browser QR & Barcode Tools (Free & Private)

All tools run 100% client-side in the web browser using WebAssembly and HTML5 Canvas. Zero images or data are uploaded to cloud servers.
